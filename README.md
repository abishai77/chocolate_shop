# 🍫 Chocolate Shop – Spring Boot E-Commerce Application

## 📌 Project Description

Chocolate Shop is a simple e-commerce web application developed using Java, Spring Boot, Spring Data JPA, Thymeleaf, and MySQL.

This application allows users to:

* Browse available chocolates
* Search chocolates by name
* Add chocolates to a shopping cart
* Remove items from the cart
* Place orders with delivery details
* Automatically update stock quantity after order confirmation

The project follows the MVC (Model-View-Controller) architecture and demonstrates CRUD operations, session management, database connectivity, and dynamic web page rendering using Thymeleaf.

## 📖 How It Works

1. User visits the home page and views available chocolates.
2. User can search chocolates using the search bar.
3. Selected chocolates are added to the cart.
4. User proceeds to checkout and enters delivery details.
5. Order details are stored in the database.
6. Product quantity is reduced after successful order placement.
